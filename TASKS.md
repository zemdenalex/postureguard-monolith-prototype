## Промпт 1: Случайные события осанки

```markdown
Добавь систему случайных событий осанки во время активной сессии.

**Контекст:**
- Сейчас usePostureSimulation меняет статус каждые 5 секунд автоматически
- Нужно сделать это более реалистичным и интерактивным

**Требования:**
1. Создать хук `useRandomPostureEvents` в `src/hooks/index.ts`
2. Во время сессии (isTracking === true):
   - Каждые 10-30 секунд (рандомно) срабатывает "событие"
   - События: "Выпрямите спину!", "Отличная осанка!", "Внимание: сутулость"
   - Событие показывается как toast/notification сверху экрана
   - При событии вызывать haptic feedback (если доступен)
   - Плохая осанка → красный toast + вибрация
   - Хорошая осанка → зеленый toast + XP бонус (+5)

3. Добавить компонент `Toast` в `src/components/ui.tsx`:
   - Появляется сверху с анимацией
   - Автоматически исчезает через 3 секунды
   - Варианты: success (зеленый), warning (желтый), error (красный)

4. Интегрировать в HomePage.tsx

**Покажи:**
1. Обновленный hooks/index.ts с новым хуком
2. Новый Toast компонент
3. Изменения в HomePage.tsx

Начни с просмотра текущего hooks/index.ts чтобы понять существующую структуру.
```

## Промпт 3: Haptic Feedback везде

```markdown
Добавь haptic feedback (вибрацию) ко всем важным действиям.

**Контекст:**
- Telegram Mini App SDK предоставляет HapticFeedback API
- Сейчас не используется

**Где добавить:**
1. Нажатие на кнопки (light impact)
2. Старт/стоп сессии (medium impact)
3. Смена статуса осанки:
   - good → success notification
   - attention → warning notification  
   - poor → error notification
4. Разблокировка достижения (success)
5. Level up (success + medium impact)
6. Завершение упражнения (success)

**Реализация:**
1. Создать утилиту `src/utils/haptics.ts`:
```typescript
export const haptics = {
  light: () => window.Telegram?.WebApp?.HapticFeedback?.impactOccurred('light'),
  medium: () => window.Telegram?.WebApp?.HapticFeedback?.impactOccurred('medium'),
  heavy: () => window.Telegram?.WebApp?.HapticFeedback?.impactOccurred('heavy'),
  success: () => window.Telegram?.WebApp?.HapticFeedback?.notificationOccurred('success'),
  warning: () => window.Telegram?.WebApp?.HapticFeedback?.notificationOccurred('warning'),
  error: () => window.Telegram?.WebApp?.HapticFeedback?.notificationOccurred('error'),
};
```

2. Интегрировать в нужные места

**Покажи какие файлы нужно изменить и какие строки.**
```

## Quick Fixes (мелкие улучшения)

### Fix: Увеличить touch targets

```markdown
Кнопки и интерактивные элементы должны быть минимум 44x44px для мобильных.

Проверь и исправь:
- Button компонент — минимум py-3
- TabItem в навигации — минимум h-12
- Card с onClick — добавить min-h-[44px]
- Toggle — увеличить размер

Используй Tailwind: min-h-11 (44px)
```

### Fix: Loading states

```markdown
Добавь loading состояния где их нет:
- Кнопка "Начать сессию" — показывать spinner при старте
- Калибровка устройства — уже есть, проверить
- Завершение упражнения — короткий loading

Использовать loading prop в Button компоненте.
```

### Fix: Empty states

```markdown
Добавь пустые состояния:
- История сессий пуста — "Начните первую сессию!"
- Нет достижений — "Выполняйте задания чтобы получить награды"
- Статистика за день пуста — "Сегодня пока нет данных"

Использовать EmptyState компонент из ui.tsx
```
